# Potrero Sector Map Trainer & Challenge (Zones 27A / 27B / 27C)

An all-in-one interactive map trainer and drag-and-drop study challenge for **Potrero, California (CA-94 / Zones 27A, 27B, and 27C)**.

## Combined Game Modes
1. **🧭 Explore Mode:** Pan and zoom across Zones 27A, 27B, and 27C. Click any landmark, road, or trail marker (`1T–18T`) to inspect tactical descriptions and coordinates.
2. **🎯 Landmark Locator:** Test your spatial recall by finding target landmarks and roads directly on the vector map.
3. **🧩 Map Challenge (Drag-and-Drop / Tap Rounds):** Complete 3 structured rounds covering **Zone 27 A/B**, **Zone 27 B/C**, and **Mixed Review** by matching road and landmark chips to their tactical clues.
4. **🛣️ Route Nav:** Calculate and highlight the shortest road/trail path between any two points across the sector.
5. **⚡ Sector Blitz:** Rapid-fire multiple-choice identification quiz with live score, streak, and accuracy tracking.

## Setup on GitHub Pages
1. Upload `index.html` and `README.md` to the root of your public GitHub repository.
2. *(Optional)* Create an `assets/` folder in your repository and upload `zone-27-ab.jpeg` and `zone-27-bc.jpeg` to view your reference study maps inside the app's **Reference Maps** modal.
3. Go to **Settings → Pages**, select the `main` branch and `/ (root)` folder, and click **Save**.
